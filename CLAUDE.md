Core principles:

- Node.js and TypeScript are the primary technologies.
- Prefer idiomatic Node.js and TypeScript approaches.
- Use modern TypeScript with strict type checking.

- Prefer explicit and meaningful types.

- Favor asynchronous, non-blocking Node.js patterns where appropriate.

- Prefer simple solutions before introducing abstractions.
- Avoid premature architecture and unnecessary complexity.

- Validate external input.

Learning principles:

- When introducing an important Node.js or TypeScript concept, explain it briefly.
- Explain why a particular Node.js approach is appropriate.
- Distinguish between TypeScript compile-time features and JavaScript runtime behavior.
- Do not hide important concepts behind abstractions unnecessarily.
- Prefer understanding the underlying Node.js mechanism before introducing a framework that abstracts it.
- When there are multiple reasonable approaches, explain the trade-offs before choosing one.

3. Identify the relevant Node.js/TypeScript concepts.
4. Identify potential trade-offs.
5. Implement the smallest useful change.
6. Add or update tests.
7. Review the implementation for correctness, simplicity and idiomatic Node.js/TypeScript practices.
